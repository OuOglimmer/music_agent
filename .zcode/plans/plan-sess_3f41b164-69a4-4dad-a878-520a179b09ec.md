## 目标：Agent 对话输出改为 SSE 流式

当前 `/chat` 是阻塞式：等模型完整生成后才返回 JSON，前端一次性渲染。改为 SSE 后，后端逐块推送文本，前端实时显示（打字机效果），中断/停止逻辑沿用现有 AbortController 机制。

### 后端改动

**1. `backend/app/agent/agent_core.py` — 新增流式方法**
- 新增 `async def process_request_stream(user_input, images, context, history) -> AsyncIterator[str]`：消息组装逻辑与现有 `process_request` 完全一致，但用 `self._get_llm().astream(messages)` 逐块 yield 文本。
- API key 缺失、认证失败等错误沿用现有异常类型，由路由转成 SSE error 事件。
- 保留原 `process_request`（流式方法复用其组装逻辑）。

**2. `backend/app/agent/routes.py` — 改造 `/chat` 为 SSE**
- 保留现有全部输入处理（会话创建/获取、文档入库、向量检索——已在线程池）。
- 新增 `_sse_event(event, data)` 辅助，输出标准 SSE 帧（`event: X\ndata: {...}\n\n`）。
- 改为返回 `StreamingResponse`（`media_type="text/event-stream"`），响应头加 `Cache-Control: no-cache`、`X-Accel-Buffering: no`。
- 生成器事件序列：
  - `event: session` → `{session_id}`（前端立即拿到真实会话 ID，先于首块输出）
  - `event: delta` → `{delta: 文本片段}`（逐块推送）
  - `event: done` → `{response: 完整回答}`（完成后把 user+assistant 消息落库并更新 updated_at）
  - `event: error` → `{detail: 错误信息}`（未配置/认证/运行时错误，同时回滚：不落库、删除新建空会话）
  - `except asyncio.CancelledError`（客户端断开）：回滚未落库消息、清理空会话（继承当前中断语义）
- 移除 `_wait_for_disconnect` 和 `asyncio.wait` 逻辑（SSE 断连由 StreamingResponse 取消机制处理）；`response_model=AgentResponse` 移除，`AgentResponse` 类保留。

**3. `backend/tests/api/routes/test_agent.py` — 适配 SSE**
- 新增 `parse_sse(text)` 辅助，把响应体解析为 `[(event, data), ...]`。
- 现有测试改为断言 SSE 事件流（session → delta → done）；覆盖消息落库、多轮上下文传递、文件/文档、error 事件。
- 中断测试改用 `client.stream(...)` 读取部分后关闭连接，断言空会话被清理。

### 前端改动

**4. 新增 `frontend/src/components/Agent/streamChat.ts`**
- `streamChat(vars, handlers, signal)`：直接 `fetch("/api/v1/agent/chat", { method: POST, Authorization header, FormData body, signal })`（走已配置的 vite 同源代理，兼容生产同源部署）。
- 用 `TextDecoder` + 按 `\n\n` 分块解析 SSE，回调 `onSession(sessionId)` / `onDelta(text)` / `onError(detail)`，返回 `{session_id, response}`。
- 中断通过 `signal`（AbortController），沿用现有停止按钮逻辑。

**5. `frontend/src/components/Agent/AgentChat.tsx` — 流式消费**
- `sendMutation.mutationFn` 改为调用 `streamChat`，在 `onDelta` 回调中通过现有 `updateMessages` 实时追加 replyId 消息的 content（打字机效果）。
- `onSuccess`：标记 done、更新缓存、invalidate 会话列表（保持现有逻辑）。
- `onError`：`AbortError`/`ERR_CANCELED` → 标记「已停止生成」；其他错误 → error 消息 + 重试（保持现有逻辑）。
- 停止按钮、会话切换、历史拉取逻辑不变。

**6. SDK/类型**：`AgentService.chat` 前端不再调用（SDK 方法保留不动，避免连锁改动）；不再使用 `AgentResponse` 响应模型。

### 验证
- 后端全量 `pytest`（含新增 SSE 测试）
- 前端 `tsc` + biome + `vite build`
- Playwright headless 实测：流式逐字渲染、生成中停止并回滚、历史会话切换加载消息

### 风险与说明
- SSE 错误以 `error` 事件 + HTTP 200 传递（流已开始无法改状态码），前端据此展示错误文案——行为与现在的错误 toast/消息一致。
- langchain `astream` 的 chunk 是完整 token，不会出现中文字符被切断的问题。
