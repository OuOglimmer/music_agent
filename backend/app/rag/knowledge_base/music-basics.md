# 零基础音乐创作速查

## 常见曲式结构

- 主歌（Verse）：讲故事、铺陈信息，旋律平稳偏低。
- 预副歌（Pre-Chorus）：2-4 句，把情绪往上推，制造期待。
- 副歌（Chorus）：全曲记忆点，音区最高、情绪最满，核心句重复。
- 桥段（Bridge）：与主副歌形成对比，提供转折或新视角，常放在第二遍副歌之后。
- 典型流行结构：前奏 → 主歌 A → 预副歌 → 副歌 → 主歌 B → 预副歌 → 副歌 → 桥段 → 副歌 → 尾奏。

## 速度（BPM）参考

- 慢速抒情 60-80：适合深情、叙事、告别场景。
- 中速 80-110：民谣、R&B、说唱常用。
- 流行/摇滚 110-160：能量足、适合合唱与现场。
- 电子舞曲 120-128：House 及多数 EDM 标准。

## 和弦进行速查

- 1-5-6-4（卡农进行）：温暖、正向，抒情与流行通用。
- 6-4-1-5：情绪化、带一点遗憾感，情歌常用。
- 1-6-4-5：50 年代进行，明朗怀旧。
- 4-5-3-6（卡农逆行/4536）：日系与华语流行副歌高频出现。
- 小调 6m-4-1-5：伤感中带力量。

## 配器分层思路

1. 前奏/主歌：1-2 件乐器（钢琴或吉他），留白多。
2. 预副歌：加入 pad（铺底音色）与轻打击，密度上升。
3. 副歌：全奏——鼓组、贝斯、和声叠层，音区推高。
4. 桥段：抽空做减法，再进最后一遍副歌时对比更强烈。

## 歌词写作要点

- 用具体意象代替抽象口号："教室后排的风扇"好于"青春的记忆"。
- 副歌第一句就是钩子（Hook），要口语、易记、可重复。
- 押韵方案：句尾单押入门，进阶可双押；音节长度尽量对称。
- 段落信息量递进：主歌给场景，副歌给态度。

## AI 音乐生成工具提示词写法（Suno 类）

- 风格标签用英文逗号分隔：如 "emotional ballad, piano-led, strings, slow tempo, female vocal"。
- 描述维度：风格 + 主奏乐器 + 情绪 + 速度 + 人声性别/质感。
- 歌词直接带段落标记 [Verse] / [Chorus] / [Bridge] 粘贴进歌词框。
- 避免互相冲突的标签（如 "acoustic" 与 "heavy EDM"）。
